Bunbooru settings

Create one under Account → API keys as Upload only, one per browser, so you can revoke it alone. It's kept in this browser's extension storage and never shown to web pages.

Images on other sites

Images usually come from a different site than the page (an image server or CDN), and most of those don't let other sites read their images. So the extension needs access to the sites you upload from: allow all sites for uploads to just work. It also sends your login cookies for that site along, so images only you can see come through. Without it, only images that allow cross-site loading can be fetched.
